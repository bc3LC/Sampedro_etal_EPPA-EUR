# outputs/

Everything here is generated by the scripts in `R/` and can be regenerated. Do not edit files by hand.

| Folder | Produced by | Contents |
|---|---|---|
| `platform/` | `01_run_medusa.R` | `di_<ens>.xlsx`, `ep_<ens>.xlsx`, `tp_<ens>.xlsx`: scenario x year (2020-2100), sheet `EUR`, for upload to the platform. Not filtered for flagged scenarios |
| `figures/` | `02_*`, `03_*`, diagnostics | PNG figures (see below) |
| `tables/` | `02_*`, `03_*`, diagnostics | CSV tables behind the figures |
| `outputs_di/` | early test | `D_impact.RData` (legacy) |

## Figures

Figures are PNG. Scripts with several figures write them into one subfolder per block.

- `02_headline_over_time*.png`, `02_diagnostic_price_vs_outcome_2030.png`
- `02_prices/`, `02_prices_diff/`: price index by commodity group per ensemble, and policy minus Ref
- `02_di_groups/`, `02_di_groups_diff/`: DI by decile, country and gender/zone (2030), and policy minus Ref
- `decomposition/` (and `decomposition/other/`): output of `R/diag/di_decomposition.R` and the price-debug figures
- `compare EPPA prices/`: EPPA sector price figures for the EPPA team
- `03_input_output/`, `03_heatmaps/`, `03_output_output/`, `03_clusters/`: blocks A-D of the scenario discovery

## Naming convention

`<script-number>_<short-description>.<ext>`. This makes it clear which script produced each file.

## Tracking

`figures/` and `tables/` are ignored by Git (only `.gitkeep`). Add a figure explicitly (`git add -f`) when it goes into a submitted version of the manuscript.
