# outputs/

Everything here is generated by the scripts in `R/` and can be regenerated. Do not edit files by hand.

- `figures/`: paper and presentation figures (PDF/SVG preferred for the manuscript, PNG for slides).
- `tables/`: summary tables (CSV, plus formatted versions for the paper if needed).

## Naming convention

`<script-number>_<short-description>.<ext>`, for example:

- `02_distribution_by_decile.pdf`
- `03_rf_importance_lowest_decile.pdf`
- `03_cart_tree.pdf`

This makes it clear which script produced each file.

## Tracking

Figures that appear in a submitted version of the manuscript can be committed; intermediate or exploratory outputs should stay untracked.
